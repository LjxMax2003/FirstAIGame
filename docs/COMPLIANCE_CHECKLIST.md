## 7. 风险项（**签字前必须裁决的两条**）

### 7.1 ❌ 「傩面」同时是玩家的武器和敌人

**事实**：

- 武器：`whip` → 显示名「**傩面·师刀**」，玩家挥的是傩面师刀。
- 敌人：`CodexDB.FOES` 里 `"id": "red", "name": "**傩面**"`，tag 为「精英」，贴图 `ELITE_RED`，图鉴说明写"没有脸的傩面，比戏台上的那张更沉"。
- 小 Boss：`"id": "nuo", "name": "**无面傩**"`，说明写"傩戏散了，面具没人摘"。

**为什么是问题**：`compliance.md` §4 原则 1 写"手艺是力量，不是怪物"，§5.3 专门注明"不把傩面/师刀做恐怖化"。现在**同一个意象既是玩家的力量，又是要打的精英怪**。玩家读到的很可能是"傩面会变成敌人"，而不是"遗忘让面具变得没有脸"。

**三个可选处置**（请顾问选一个，我按选择改）：

| 方案 | 做法 | 代价 |
|---|---|---|
| A（推荐） | 敌人改名：`傩面` → **「失面」**，`无面傩` 保留（它本来就是"找不到脸"的叙事，且是 Boss 有专属说明）。玩家侧「傩面·师刀」不动 | 改 `CodexDB.FOES` 一个字符串 + 图鉴断言；`V71Content` 有 id 断言但 name 不参与判定，风险低 |
| B | 保留名称，但在图鉴说明里**明写"这不是傩戏本身，是没人来摘的那张道具面具"** | 靠文案兜，视觉上仍可能误读 |
| C | 保留现状，由顾问出具书面理由（"面具脱离戏台即失其神，正是本项目的主张"） | 需要顾问愿意背书 |

> 我的判断：**A 最省事也最安全**，B 是次选。C 只有顾问真愿意签字才成立。

### 7.2 ❌ 「铜锣」「墨斗」两门手艺没有合规依据

**事实**：`compliance.md` 是 v0.1 策划阶段写的，列了 10 项手艺，**不含铜锣、不含墨斗**。v5 把武器从 6 加到 9，新增的正是这两门。现在它们有：武器（`gong` / `inkline`）、图鉴条目、升级卡文案，但**没有对应的名录核对与转译原则**。

**风险**：图鉴里那两条设定说明（"铜锣一响，声波荡开" / "墨线绷直，一线穿透"）目前**没有文化依据支撑**。若顾问审到这两条，会问"依据在哪"。

**请求**：请顾问给出这两项的归类意见 ——

- 铜锣：归入"民间锣鼓 / 绛州鼓乐"体系，还是单列"铜响乐器"？参考地域？
- 墨斗：归入"传统木工技艺 / 传统木结构营造技艺"，还是只作"通用工具"处理？称谓是否用"墨斗"（不写"墨斗线"？）

**在顾问答复前**：图鉴这两条的说明保持现状（只写游戏内表现，不写任何历史/地域断言）—— 这已经是当前最保守的写法。
