## 0. 结论先行（TL;DR + 三痛点对照）

| 实机痛点（v3.1） | v5 怎么解决 | 验证（模型） |
|---|---|---|
| **10min 后可挂机**（太轻松） | 中期墙（浆壳兵）+ **周期潮涌/小 Boss** 持续尖峰 + **主动技·震吼** 逼操作 | 稳态 R 压到 0.4–0.6；潮涌尖峰 0.17–0.33；`cur` 旧线 30min R≥1.04（可清屏）↘ |

## 1. 实机痛点诊断（用模型证红，再谈改）

跑 `v5_model.py` 的 `cur` 变体（复刻实机：exp2.0 / 无等级上限 / 无浆壳 / 无潮涌）：

```
00:00  R=0.46      开局
05:00  R=2.80      雪球
15:00  R=2.16
25:00  R=1.01
30:00  R=1.04      ← R≥1：清屏压力被完全覆盖 → 可以挂机
```

**证红结论**：实机 R 全程 ≥1，且后期仍 ≥1，**根本没有"打不过"的窗口**——这正是"10min 后挂机"的根因：难度没跟上数值，玩家躺着也能清。R<1 才是幸存者-like 该有的"必须走位/操作"状态。

三大痛点跨层归因：
1. **可挂机** = 难度曲线全程在 R≥1，无任何需要主动应对的尖峰。
2. **技能升满快** = exp2.0 + 无 cap，武器 Lv8 在 10min 内达成，之后无选择。
3. **无局外无法通关** = 终端输出（R 后期、Boss 血 11000）只有叠了局外 1.35× 才够，局内独力达不到通关门槛。

## 2. 设计目标与原则

- **局内自洽**：通关门槛必须能被"干净局内构筑"独立跨过；局外加成是舒适度，不是门票。
- **进程延展**：等级/卡池预算要撑满 30min，且 Lv8 之后仍有有意义的选择（精炼），不让构筑在 10min 定型。
- **持续威胁**：用"中期墙 + 周期潮涌 + 小 Boss + 主动技"制造**贯穿全程**的尖峰，杜绝"过了某点就能挂机"。
- **机制先行于数值**：先定"为什么好玩/为什么必须操作"，再用模型定参数。
- **主题自洽**：所有新增仍在"百工守艺人 / 傩仪"母题内。

## 3. 技能机制完善

### 3.1 铜锣（gong）— aura / AoE（保留 v4）
大半径低频光环（半径 150，满级 8 目标），自带 `amp=0.12`：对结壳敌人 +12% 伤（轻微破壳）。第二光环位，补花灯之外的覆盖范围。

### 3.2 墨斗（inkline）— line / 单点 ★破壳核心（保留 v4）
直线穿透单点，**满级单体 100**（全游戏单点头牌）。关键 `shell_bonus=1.80`：对结壳敌人 ×1.80，是浆壳兵的官方解。

### 3.3 木版年画（print）— zone / AoE 高爆发（保留 v4）
延迟 `0.45s` 落点范围爆发（半径 105），高基础伤 30，扎堆中心密度 `focus=1.8`。

### 3.4 武器机制打磨（吸收参考方案，解决"武器没表达深度"）

| 武器 | 旧问题（读代码） | v5 机制（首版值） | 落地文件 |
|---|---|---|---|
| **打铁花** | `hit_cap` 耗尽只静默消失，无二次伤 | **引爆型**：命中第 1 个敌人时在落点炸 `explode_radius=76`、`explode_ratio=0.65`，**每发只引爆一次**（防同一群反复炸）；扎堆场景总伤 +35~47% | `WeaponManager.update_bullets` + `WeaponDB` |
| **花灯** | 与远程抢击杀；`slow 0.15` 读不出 | 减速 `0.15→0.22`；**对已被减速敌人 +20% 伤**（奖励"留怪在圈里"） | `WeaponDB` + `Enemy` 受击分支 |
| **糖画** | `pierce 1` 打两下就停 | **穿透里程碑**：Lv4 / Lv8 各 +1 穿透（不是线性给） | `WeaponDB.count_at` |
| **皮影** | 环绕撞到无反馈 | 命中给 **0.15 击退**（顿一下，读出"撞"） | `WeaponManager.fire_phone` |
| **剪纸** | `bounce 3` 固定距离，两怪互弹到死 | 弹射距离随 `area` 缩放；**同一目标第 2 跳后 -30%**（防互弹） | `WeaponManager.fire_blade` |
| **师刀** | `length_cap 260` 硬帽，Lv8 后无感 | **Lv7/Lv8 扫两次**（各 60% 伤），用"次数"替代"长度"成长 | `WeaponManager.fire_whip` |

> ⚠️ 打铁花引爆与花灯加伤会加剧"远程抢光环击杀"，**必须同批改**（参考方案 §6.2）。任何 `damage/pierce/radius` 改动都需回填 `v5_model.py` 重跑收敛带。

### 3.5 主动技：傩面替身·震吼 ★防挂机核心（v5 新增）

参考方案 §5.2 明确指出"**没有主动技是本作真正的机制缺口**"。v5 补一个：

- **机制**：玩家主动触发（竖屏单摇杆下用"双击/长按"或独立按钮），CD 25s。
  - **震吼**：以自身为中心半径 220 的范围爆发，伤害 = **250% 当前单体 DPS**；
  - **替身**：触发后 **0.7s 无敌 + 向摇杆方向冲刺**（脱围）。
- **为什么是防挂机核心**：潮涌尖峰（§6）把 R 砸到 0.17–0.33，纯靠走位会被围死；震吼是设计好的"尖峰应对动作"，**把 22–45s 的危机变成一次主动操作**，玩家必须看时机放，而不是挂机。
- **数值边界**：CD 25s（一场约放 40+ 次）；爆发伤害随构筑缩放（不写死绝对值，避免通胀）；无敌 0.7s 严格上限，防滥用成无敌帧。
- **不进 R 模型**：主动技是生存/脱围工具，不参与 DPS 归因，文档定性说明。

## 6. 持续威胁 / 防挂机（解决"10min 后可挂机"）

靠三件套制造**贯穿全程**的尖峰，而不是"过一道墙就能躺"：

1. **中期墙：浆壳兵**（§8）——8–20min 杂兵结壳，纯 AoE 效率 ×0.75，逼出"带墨斗破壳"决策。
2. **周期潮涌（v5 新增）**：每 10min 一波（10/15/20/25/30min 起始），持续 22–45s，刷新 ×1.35→1.55、精英 +0.08→0.16。**只做尖峰不做持续塌缩**——尖峰之间回到稳态，玩家能缓口气但不能永久躺。
3. **小 Boss**：12/18/24min 各刷新一只精英 Boss（高血、接触重），强制转火。
4. **主动技·震吼**（§3.5）：潮涌/小 Boss 尖峰的**设计内应对动作**，把危机变成一次主动操作。

> 模型里潮涌把瞬时 R 砸到 **0.17–0.33**（稳态为 0.4–0.6）。这不是"数值崩了"，是"你必须放震吼/走位/开盾"的信号。若真机潮涌死亡率过高，优先下调 `SURGES` 的 `lam_mult` 或 `dur`（回滚见 §10），不要直接加总数值。

## 7. 局内自洽（解决"无局外无法通关"）

| 杠杆 | v3.1 | v5 | 效果 |
|---|---|---|---|
| Boss 血（30min） | 11000 | **7000** | 干净局内单体/混合构筑可在 5–9s 击杀（见 §9.3），不再需局外 1.35× 硬托 |
| 更鼓 | 1.32（25min 封顶） | **1.40（30min 再加一更）** | 终局确定性成长再抬一档 |
| 精炼 | — | +6%/级 ×3 | 终局 DPS 叠加层 |

**为什么局外变可选项**：5 种构筑的 Boss 击杀均 5–9s（纯局内），通关门槛被局内独立跨过；更鼓/精炼/护盾把存活率托在可生还区间。局外 1.35× 只是"更轻松"，不是"必需"——痛点 ③ 因此闭环。

> R<1 是幸存者-like 常态（屏上限 400，靠走位稀释而非 100% 清除）。**真正验收是 30min Boss 击杀窗口**，而非全程 R≥1。

## 8. 中期难度：浆壳兵（保留，定位为持续威胁一环）

- **机制**：8:00 起杂兵按时间窗结壳，8–17min 满强度，17–20min 线性溃散，20:00 消失。
  - 结壳杂兵 **血 ×1.40**、**吃 AoE ×0.75**（吃单点 ×1.0、吃墨斗 ×1.80）。
- **定位**：与潮涌/小 Boss 共同组成"全程威胁"，但**中期（10–17min）是它单独主导的墙**——纯 AoE 流 R 跌到约 0.53–0.63，带墨斗则翻墙。这是机制层面的中期决策，非纯数值增压。
- 落点：`Enemy.gd` 加 `shelled` 标志与受击倍率分支；`WaveTable.gd` 按时间窗上壳。

## 10. 验证设计（机枢采纳门槛 · 六项齐全）

| 字段 | 内容 |
|---|---|
| `decision` | 采纳 v5：在 v4 基础上 +精炼 +主动技·震吼 +周期潮涌/小Boss +进程延展(exp2.6/cap60) +局内自洽(Boss7000/更鼓1.40)；吸收参考方案 6 项武器打磨 + 打铁花进化。 |
| `evidence_level` | **L2**（半解析模型，基于战斗公式跑出 R 曲线/进程表/极限组合；非真机 A/B）。允许结论："模型口径下，10–17min 中期墙 R≈0.53–0.63、潮涌尖峰 0.17–0.33、5 种构筑 Boss 击杀 5–9s、10min 仅 1 满级。" |
| `primary_bottleneck` | **持续威胁不足 + 进程过早定型 + 终端输出低于通关门槛**，三者并列（对应三大痛点），非单点。 |
| `released_variables` | 本次释放 **2 个主变量**：`HP_EXP 1.70→1.62`（终端需求缓增）+ `BOSS_HP 11000→7000`（通关门槛下调）。其余（潮涌/精炼/主动技/武器打磨）均 `held_constant` 钉死。 |
| `success_criteria` | 跑前写死：① 稳态 R 在 10–17min 落 **0.45–0.75**（墙但不秒杀）；② 潮涌尖峰 R 不导致**中位死亡率 >60%**；③ 5 种构筑 Boss 击杀 **≤12s**（局内可通关）；④ 10min 满级武器数 **≤2**。 |
| `rollback_trigger` | 若真机：① 潮涌中位死亡率 >60% → 下调 `SURGES` 的 `lam_mult/dur`；② 10min 满级武器 >2 或仍有大量 pick 闲置 → 回调 `exp` 至 2.7 / `cap` 至 54；③ Boss 击杀 >12s → 回调 `BOSS_HP` 至 8000。 |

**四类信号（跑前写死）**：
- `pass`：上述 4 条 success_criteria 全满足。
- `fail`：潮涌中位死亡率 >60% 或 10min 满级 >2。
- `confounded`：若同时动了潮涌强度与精炼倍率 → 不可归因，作废重测。
- `stop`：潮涌尖峰出现"放震吼仍必死"（说明尖峰超出生存工具上限）→ 暂停，先降尖峰。

**归因探针（若 fail，先证红再动）**：列 ≥3 跨层候选——(a) 潮涌倍率过狠；(b) 中位玩家没抽到护盾/回春（防御卡稀释）；(c) 主动技 CD 过长/无敌帧不足。用判别性探针分"可能/不可能"两组，确认主瓶颈后再动第二个变量；探针期间动第二变量 → 归因作废。
